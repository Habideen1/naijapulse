# NaijaPulse

NaijaPulse is a customer intelligence platform being built to help Nigerian businesses understand customer feedback written in Nigerian Pidgin, English, slang, and mixed-language expressions.

The initial focus is on fintech customer experience teams. The aim is to analyze feedback and show sentiment patterns in the language customers actually use.

## Status

**Early development. No features are implemented yet.**

The repository currently contains only project setup. The planned MVP is listed below and is not yet built or tested.

## Planned MVP

- User registration and authentication
- Company accounts with separated company data
- Customer feedback submission
- Sentiment classification (positive, neutral, negative)
- Feedback history with filtering and pagination
- Dashboard with sentiment distribution and trends over time
- API documentation
- Automated tests and deployment

## Planned tech stack

- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Python, Django, Django REST Framework
- **Database:** PostgreSQL
- **Machine learning:** Python, pandas, NumPy, scikit-learn, Jupyter notebooks

## Project background

NaijaPulse builds on the idea behind the Nigerian Pidgin Sentiment Analyzer (3MTT capstone project) and is developed in a clean repository with fresh dataset research and a new, documented ML pipeline.

The claim that existing sentiment tools handle Nigerian Pidgin poorly is a hypothesis to be validated through research and customer interviews. It is not an established finding.
